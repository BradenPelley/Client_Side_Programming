Store Code Review

Project Overview
This project is a grocery store web application built using HTML, CSS, and JavaScript. The goal of this assignment was not to build the project from scratch, but to carefully investigate existing code. I reviewed the structure, styling, and JavaScript functionality and added detailed comments explaining how everything works.

The application allows users to:
-Enter quantities for grocery items
-Calculate a total price
-Print a formatted receipt
-Automatically reset the cart after 15 seconds of inactivity


Professional Improvement Suggestion
Improvement: Add Proper <label> Elements for Accessibility

The Problem:
The number input fields for each grocery item do not currently use associated '<label>' elements. While the application works visually, this may cause accessibility issues for users who rely on screen readers or assistive technologies. Without labels, screen readers may not clearly communicate what each input field represents.

Why This Matters
Accessibility is an important part of professional web development. Adding proper labels:
-Improves usability
-Follows web development best practices
-Makes the form more accessible
-Makes the overall project more professional

Improved Code Example
Current version:
<input type="number" id="milk" value="0" min="0" oninput="startTimer()" />

Improved version:
<label for="milk">Milk Quantity</label>
<input type="number" id="milk" value="0" min="0" oninput="startTimer()" />

The "for" attribute connects the label to the input field using the matching id, which allows screen readers to properly identify the input.
