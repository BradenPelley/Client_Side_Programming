Responsive Card Slider

Description:
This project is a responsive card slider built using HTML, CSS, and JavaScript. It allows users to browse through different cards using navigation arrows or pagination.

Reference Tutorial:
https://www.youtube.com/watch?v=VUtJ7FWCfZA&list=PLpwngcHZlPadhRwryAXw3mJWX5KH3T5L3&index=11

The original tutorial demonstrates how to create a responsive slider using the Swiper.js library.

My Improvement:
I added an automatic sliding feature using Swiper’s auto play functionality. The cards now move every few seconds without any user interaction. I also added a pause-on-hover feature, which stops the auto play when the user hovers over the slider. It allows them to focus on the specific content.

What I Learned:
-How to use the Swiper.js library.
-How to implement auto play functionality.
-How to use event listeners in JavaScript.
-How responsive design works using breakpoints.
